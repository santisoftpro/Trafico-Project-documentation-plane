# 1. Purpose

This document defines user stories that describe the functionality required by each user type.

---

# 2. Business Owner Stories

## Company Management

As a Business Owner,

I want to register my company,

So that I can use Trafico.

---

As a Business Owner,

I want to invite employees,

So that they can manage conversations.

---

As a Business Owner,

I want to view analytics,

So that I can monitor business performance.

---

# 3. Operator Stories

As an Operator,

I want to receive new conversations,

So that I can assist customers.

---

As an Operator,

I want to assign suppliers,

So that customer requests are fulfilled.

---

As an Operator,

I want to search conversations,

So that I can quickly find customer information.

---

# 4. Customer Stories

As a Customer,

I want to communicate through WhatsApp,

So that I do not need to install another application.

---

As a Customer,

I want quick responses,

So that my request is handled efficiently.

---

# 5. Supplier Stories

As a Supplier,

I want to receive requests,

So that I can provide quotations.

---

As a Supplier,

I want to communicate without unnecessary delays,

So that work is completed faster.

---

# 6. Administrator Stories

As a System Administrator,

I want to monitor infrastructure,

So that platform availability remains high.

---

# 7. Summary

These user stories define the expected functionality from the perspective of each user group and provide the foundation for sprint planning and feature development.
