# 1. Purpose

Defines how the Trafico interface adapts across different screen sizes.

---

# 2. Supported Devices

Desktop

Tablet

Mobile (Future)

---

# 3. Breakpoints

Mobile

0–767px

Tablet

768–1023px

Desktop

1024px+

---

# 4. Layout Rules

Desktop

- Sidebar always visible

Tablet

- Collapsible sidebar

Mobile

- Bottom navigation
- Drawer menu

---

# 5. Tables

Large tables should:

- Support horizontal scrolling.
- Allow column hiding.
- Support filtering.

---

# 6. Forms

Forms should:

- Stack vertically on smaller screens.
- Expand on desktop.
- Maintain readable spacing.

---

# 7. Summary

Responsive layouts ensure Trafico remains usable across supported devices.
