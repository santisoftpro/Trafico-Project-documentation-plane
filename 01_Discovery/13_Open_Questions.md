# Open Questions

Document ID: D13

Project: Trafico

Version: 1.0

Status: Draft

Last Updated: July 2026

---

# 1. Purpose

This document records unresolved questions identified during the Discovery phase.

These questions must be answered before finalizing the Product Requirements Document (PRD) and beginning implementation.

---

# 2. Business Questions

- Who owns the WhatsApp Business Account?
- How are subscription plans structured?
- How many operators can a company have?
- Can suppliers participate in multiple companies?
- What conversation retention policy is required?

---

# 3. Functional Questions

- Should messages be automatically relayed or require operator approval?
- Can operators edit messages before forwarding?
- Can customers upload all supported WhatsApp media types?
- Should conversations automatically close after inactivity?

---

# 4. Technical Questions

- Which WhatsApp provider will be used?
- Which cloud provider will host the platform?
- What notification channels are required?
- What monitoring solution will be implemented?

---

# 5. Security Questions

- How long should messages be retained?
- What audit logs are required?
- What compliance requirements apply?
- What user roles require administrative privileges?

---

# 6. Future Considerations

These topics are intentionally deferred:

- AI-powered conversation analysis
- CRM integrations
- Mobile applications
- Public APIs
- Workflow automation

---

# 7. Summary

All open questions should be reviewed with stakeholders before entering the Product Definition phase to reduce uncertainty and implementation risk.
