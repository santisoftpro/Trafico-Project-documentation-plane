Document ID: E08

Project: Trafico

Version: 1.0

Status: Draft

Prepared By: Santisoft Ltd

Last Updated: July 2026

---

# 1. Purpose

Defines the standards for reviewing code before it is merged into the main codebase.

---

# 2. Review Objectives

Ensure:

- Correctness
- Readability
- Security
- Performance
- Maintainability

---

# 3. Reviewer Checklist

Verify:

- Requirements are implemented.
- Code follows standards.
- No duplicated logic.
- Error handling exists.
- Tests are included.
- Documentation is updated.

---

# 4. Review Rules

- Review the code, not the developer.
- Provide constructive feedback.
- Explain suggested improvements.
- Approve only when requirements are met.

---

# 5. Pull Request Requirements

Every pull request must include:

- Description
- Linked issue
- Testing evidence
- Screenshots (if UI changes)

---

# 6. Summary

Code reviews improve software quality and promote knowledge sharing across the team.
